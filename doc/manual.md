# 鸿蒙版 AI 阅读器使用说明书

欢迎使用 **AI 阅读器**（鸿蒙版）！这是一个在手机上免费看小说的阅读 App。你可以用它看网络小说、本地下载的电子书（TXT、EPUB、PDF、MOBI 等），还可以订阅新闻博客（RSS）。内置的 AI 助手还能帮你自动生成书源、修复失效书源、把网页上的小说一键导入书架。

这份说明书是写给**不熟悉技术**的普通用户的，你不需要懂任何编程知识，跟着操作即可。

> 小提示：本 App 里的书和内容都来自互联网上公开的网站，App 本身不提供任何内容。文中所说的"书源"就是你订阅的那些网站，需要你自己添加。

## 1. 快速上手：10 分钟开始看书

第一次打开 App，你需要先做一件事：**导入书源**（书源 = 能搜到小说的网站列表）。没有书源，就像没有商店的购物车，什么都搜不到。

### 第 1 步：导入书源

1. 点击底部导航栏最右边的 **「我的」**。
2. 点击 **「书源管理」**。
3. 点击右上角 **「导入」** 按钮，选择一种方式：
   - **选择本地文件**：如果你有别人发给你的书源文件（.json 格式），选这个。
   - **粘贴 JSON 内容**：把别人分享给你的书源代码粘贴进来（书源通常在网上以代码形式分享，例如在"阅读"App 的公众号或书源分享网站上复制）。
   - **从 URL 导入**：输入书源文件的下载链接。
4. 导入后会弹出列表，显示哪些是**新增**、哪些是**更新**，直接点底部 **「导入选中」** 即可。
5. 回到书源列表，确认书源后面的**开关是打开状态**（绿色/开启）。

> 如果没有书源怎么办？书源一般在搜索引擎搜"阅读APP 书源"、"书源分享"等关键词可以找到分享文章，或者从朋友那里获取。App 内置了一些常用书源，也可以直接使用。
>
> **没有书源也可以让 AI 帮你做**：在「书源管理」页点右上角 **「AI」** 按钮，输入你常看的小说网站的网址（比如"www.xxx.com"），AI 会自动分析这个网站并生成一个可用的书源，保存后就能搜索了（详见第 8 节"AI 生成书源"，需先配置 AI 服务）。
>
> **不想折腾书源？还有另一条路**：不导入书源，直接用「搜索 → 在线」标签，用网页搜索引擎找到你想看的小说，点"导入当前页"让 AI 帮你把整本书加入书架（详见第 5 节）。这样一本书都不需要书源。

### 第 2 步：搜索一本小说

1. 点击底部 **「书架」**，再点右上角 **「搜书」** 按钮。
2. 输入书名，点击搜索。
3. 稍等几秒，搜索结果会一条条出现。点击感兴趣的结果，进入书籍详情页。

> 如果还没有明确想看的书，**也可以不搜索，直接去"逛"**：切到底部 **「发现」** 页签——这里有书源网站的分类排行榜（像逛书店），还有两个"书荒救星"：
>
> - **优书网**：评分网站，可以按分类、年代等条件筛选，看看高分书有哪些；
> - **龙空推书**：论坛书友的推荐帖，让 AI 把帖子整理成书单。
>
> 在优书网和龙空里**点击任何一本书，App 都会自动跳到搜索页帮你搜这本书**（可选"书源搜索"或"在线搜索"），找到后加入书架就能看，非常省事（详见第 4 节）。

### 第 3 步：开始阅读

1. 在书籍详情页点 **「阅读」** 按钮（右下角浮动按钮）。
2. 进入阅读页后，**点击屏幕中央**可以呼出菜单（目录、设置等）。
3. 点击屏幕**左右两侧**翻页。

恭喜，你已经会用了！下面详细介绍每个功能。

## 2. 主界面总览

打开 App 后，底部有 4 个页签，分别是：

| 页签 | 作用 |
|------|------|
| **书架** | 你收藏的书都在这里，点击直接继续阅读 |
| **发现** | 逛书源网站的分类/排行榜，像逛书店一样找书 |

| **我的** | 所有设置和工具（书源管理、字体、备份等） |

在平板上（屏幕较宽），「我的」页面会变成左侧菜单 + 右侧内容的分栏形式，功能不变。

## 3. 书架：你的私人书库

书架页是打开 App 后第一眼看到的页面，展示你收藏的所有书。

### 一本书长什么样

每本书显示：封面、书名、作者、**读到哪一章**、最新章节（绿色高亮）、阅读进度条、最近阅读时间。如果有更新，右下角会有红色"+N"数字提醒你这本书更新了几章。

### 基本操作

| 操作 | 效果 |
|------|------|
| **点击书** | 直接继续阅读（从上次读到的地方开始） |
| **长按书** | 弹出菜单：查看详情 / 关闭更新（看完的书不再提示更新）/ 清除缓存 / 删除 |
| **点列表右侧 ✕** | 直接移出书架 |
| **下拉刷新** | 检查所有书架书籍是否有更新（会联网） |
| **右上角 ☁ 按钮** | 打开"在线书库"，从云端书库下载书（见第 9 节） |
| **右上角 搜书 按钮** | 进入全局搜索页找书 |

### 书架顶部的工具

- **搜索框**：输入书名或作者，快速筛选书架里的书。
- **分组标签**：书架的书可以分组（全部 / 在读 / 已完本 / 你自己建的分组），点击标签只看那一组。
- **布局切换**（方块图标）：在"列表视图"和"宫格视图"之间切换。
- **排序**：点击切换排序方式——最后阅读 / 书名 / 更新时间 / 手动排序。
- **⋮ 更多菜单**：包含——添加远程书籍、添加本地书籍、更新目录、布局设置、分组管理、添加URL、选择模式、书架管理、缓存/导出、导出书架、导入书架、日志。

### 添加本地电子书

想看你手机里下载的 TXT / EPUB / PDF / MOBI 小说？

1. 点击书架右上角 **⋮** 菜单 → **「添加本地书籍」**。
2. 在文件选择器里找到你的电子书文件（一次最多选 20 本）。
3. 导入完成后书就出现在书架上了。App 会自动识别章节，点击即可阅读。

> 支持的格式：TXT、EPUB、MOBI、AZW、AZW3、PDF。

### 批量管理（选择模式）

在 ⋮ 菜单里点 **「选择模式」**，然后可以勾选多本书，底部出现操作栏：**全选 / 导出 / 移除**，适合批量整理书架。

### 导出和导入书架

- **导出书架**：把书架里的书（书名、进度、分组信息）保存成一个 JSON 文件，可以发给朋友或留作备份。
- **导入书架**：把别人导出的书架文件导入，App 会自动匹配书源、下载目录、加入书架。

## 4. 发现：逛书店找书

「发现」页签就像一个网上书店，带你逛各个书源网站的分类和排行榜。它有 3 个子页面：

### 书源发现

- 列表展示所有开启了"发现"功能的书源。
- **展开**一个书源，会显示它的分类按钮（如"玄幻"、"都市"、"完本"），点分类即可进入该分类的书籍列表，像逛书店一样按分类找书。
- 部分书源还有"线路切换"、"登录"等按钮，按需要点击。

### 优书网发现

优书网是一个小说评分网站，这里有两个子页面：**书库** 和 **书单**。

**书库（可筛选、可排序）**

1. 页面顶部有一排**筛选条件**（可以点右上角"收起筛选"隐藏），来自优书网自己的筛选表，通常包含几组：
   - **分类**（玄幻、都市、武侠等）、**年代**、**首发站点**、**状态**（连载/完本）等，以及**排序方式**（如按推荐热度、点击量、更新时间等排序）。
   - 每组可以点一个选项（如"玄幻"+"2024年"），组合起来就能筛出你想要的书的范围。
2. 下方就是**书籍列表**，每本显示：书名、**评分**（如"4.5"）和**评分人数**、作者、**总点击**、更新时间、连载状态（如"完本"）。
3. 列表顶部显示"作品列表 · N 条已加载"；**下拉刷新**重新加载，**滑到底部**自动加载下一页。
4. **点击任意一本书**，会弹出"选择搜索方式"：**书源搜索**（用你的书源搜这本书）或**在线搜索**（用网页搜索引擎找），选择后自动跳转到搜索页并带入书名和作者。

**书单**：优书网用户整理的推荐书单列表，同样可以浏览和点击搜索。

### 龙空推书：AI 帮你整理论坛推荐

龙空（龙的天空论坛）是著名的小说论坛，书友会发帖推荐好书。这里的特色是：**AI 把帖子里的推荐内容自动整理成一份"书单"**。页面分两个标签：**选帖子** 和 **分析结果**。

**第一步：选帖子**

1. 顶部有帖子筛选方式：**全部 / 精华 / 最新 / 今日热门 / 标签**。
   - 选「标签」后会出现标签列表（如"仙侠""粮草"等），点一个标签只看该标签下的帖子。
2. 帖子列表每条显示：标题、作者、发布时间、回复数、浏览数（精华帖有"精"标记），**点帖子或勾选框选中它**。
3. 操作栏提供两种批量选帖方式：
   - **全选 / 全不选**：选中/取消当前已加载的全部帖子。
   - **选择"最近 N 天"**（下拉可选 1–7 天）：自动翻页把最近 N 天内发的帖子全部收集起来并自动勾选——这是最省事的选帖方式，配合"精华"筛选用效果最好。
4. 选好后点底部 **「分析选中的帖子（N）」** 按钮。
   - 前提：需要先配置 AI 服务（见第 9 节"大模型配置"）。
   - 部分板块要求**登录龙空**才能浏览，页面会提示你登录。

**第二步：AI 分析**

点击分析后，App 会：

1. 逐个读取选中帖子的**正文内容**（显示"读取帖子正文 X/N"进度）；
2. 把内容交给**大模型**，自动识别出帖子里推荐了哪些书，并整理出**书名、作者**和**推荐理由**（AI 综合帖子观点，有争议时同时说明优缺点）；
3. 生成一条分析记录并自动切换到**「分析结果」**标签。

**分析结果**

- 顶部是**历史记录条**：每次分析保存为一条记录（显示"时间 · 筛选方式"和"N 个帖子 · M 本书"），点击切换查看，可删除。最多保留 10 条。
- 书籍列表每条显示：**序号、书名、作者、推荐理由**，右侧有"搜索 ›"。
- **点击任意一本书**：弹出选择"书源搜索"或"在线搜索"，跳转搜索页带入书名和作者，找到后即可加入书架阅读——整个流程从"论坛帖子"到"书架里的书"就打通了。

## 5. 搜索：精准找书

点击书架右上角的「搜书」，进入全局搜索页。这里有两个模式：

### 「书源」标签：用你的书源搜索

- 输入书名，点搜索。App 会**同时用所有启用的书源搜索**（默认同时搜 16 个，可在设置里调整），结果会一条条实时出现，不用等全部搜完。
- 同一个名字、同一个作者的书如果多个网站都有，会自动**合并成一条**，并显示"来自 N 个源"，点击可以看具体是哪几个源。
- 页面底部显示当前已加载的书源数量。

### 「在线」标签：用网页搜索引擎找（支持 AI 智能导入）

当书源搜不到（比如很冷门的书）时，可以用网页搜索引擎找。找到之后，App 会请 AI 帮你把整本书导入书架——不需要你懂任何技术，也不需要书源。

#### 方式一：先搜索，再导入（推荐）

1. 选择搜索引擎（默认必应，也可选百度、搜狗、神马、Google）。
2. 输入书名搜索，搜索结果在网页中打开。也可以直接**粘贴一个小说网页的网址**，跳过搜索。
3. 在搜索结果里点进具体的小说页面，翻到这本书的**详情页或目录页**（注意：停留在搜索结果列表页时不能导入，App 会提示你先进入书的页面）。
4. 确认页面无误后，点 **「导入当前页」**。
5. App 会弹出确认框，请确认后等待 AI 工作，全程有进度提示：
   - **抓取页面** → **分析书名、作者、封面等** → **分析整本目录** → **用真实章节验证正文规则**（AI 会用最多 3 章样本来确认正文真的能提取出来，不行就不会保存）→ **写入书架**。
6. 完成后提示"导入成功！已生成 N 章目录"，此时书已出现在书架里。
7. 之后可以选择「立即后台缓存全书」（一次性把整本书下载到手机，离线也能看）或「稍后缓存」（阅读时按需加载）。

> 这种方式（AI 智能导入）适合书源里找不到的书。App 的 AI 会像"看懂网页"一样自动解析出书名、目录和正文，**不需要书源，也不需要任何规则**。导入后这本书在书架里就是一个普通书架书籍，阅读、刷新连载、缓存等一切功能照常可用。
>
> 前提：需要先配置 AI 服务（见第 9 节"大模型配置"）。如果尚未配置，App 会提示你先去设置。

## 6. 书籍详情页：了解一本书

点击搜索结果或书架里的书（通过长按 → 详情）会进入书籍详情页，展示：

- **书名、作者、分类、字数、章数、更新时间、连载状态**
- **书籍简介**（超过一定长度可以展开/收起）
- 你的**阅读进度**（读到哪一章、什么时候读的）
- 备注信息

页面上的主要按钮：

| 按钮 | 作用 |
|------|------|
| **加入书架 / 已在书架** | 收藏或移出书架 |
| **查看目录** | 看这本书的章节目录 |
| **书源** | 查看/切换这本书可用的其他书源 |
| **阅读记录** | 查看这本书的阅读历史 |
| **阅读**（右下角悬浮） | 直接开始阅读 |

### 更多菜单（右上角 ⋮）

- **登录**：某些网站需要登录才能看书（如微信公众号文章、部分论坛），点这里登录。
- **刷新**：重新获取这本书的最新状态。
- **关闭更新**：书已看完，不再提醒更新。
- **换封面 / 分组 / 备注 / 编辑**：自定义这本书的封面、归属分组、备注和书名作者。
- **导出 / 清缓存 / 移出书架**：管理这本书的数据。

## 7. 阅读器：舒服地看书

阅读是 App 的核心，这里详细介绍阅读界面的所有功能。

### 打开菜单

阅读时**点击屏幕中央**，会出现顶部菜单、中间进度条、底部菜单。

### 翻页操作：分页模式

阅读页默认是**分页模式**（一页一页翻），屏幕被分成 3×3 九个区域：

- **点击左右两侧**：上一页 / 下一页。
- **点击上方角落**：上一章 / 下一章。
- **左右滑动**：也可以滑动翻页。
- 每个区域的动作都可以在「设置」里自定义（见下文"触控区域"），例如把左侧改成"上一章"、把右上角改成"添加书签"等。
- 翻到一页的最后一页再点下一页，会自动接上下一章（连续阅读，不用回目录）；反过来也一样。

### 滚动模式：像刷网页一样连续看

在阅读「设置」面板里把「阅读模式」切成 **「滚动」**，正文就变成连续滚动阅读：

- **手指上下滑动**，内容像网页一样连续往下刷，不再一页一页翻。
- **滚动到底部**会自动接上下一章，**滚回顶部**自动回到上一章——上下章和当前章是无缝衔接的（同一屏里你能看到上一章的结尾和下一章的开头），完全不用停顿、不用手动切章。
- 滚动模式退出后位置会被记住，下次进来接着看；切回分页模式时也会尽量停在原来读到的位置。
- 两种模式随时切换（阅读「设置」→「阅读模式」），选择会记住，下次打开还是你选的模式。

> 提示：分页模式适合逐字细读、精确翻页；滚动模式适合快速浏览、连读大段内容。两种模式都支持底部菜单、目录、朗读、换源等全部功能。

### 顶部菜单

- 返回按钮（退出阅读）
- 书名 + 章节标题 + 当前使用的书源名称（可长按复制章节地址）
- **「搜」按钮**：进入**书内搜索**——在当前书的所有章节里搜关键词，结果点击即可跳到对应位置（支持搜索历史、正则等高级选项）。
- **「签」按钮**：为当前位置**添加书签**，可以写一句原文摘录和笔记。
- **「•••」更多工具**：
  - **更换书源**：这本书在别的网站也有，换一个源继续看（整本换源会保留阅读进度）。
  - **缓存章节**：把后面的章节下载到手机，离线也能看（详见下文"离线缓存"）。
  - **刷新当前章**：内容加载失败时重新加载。
  - **替换净化**：开启或关闭"净化"功能（自动去掉正文里的广告、无关文字，见第 9 节）。

### 中间进度条

- 上一章 / 下一章按钮。
- 拖动**滑块**跳到任意章节。
- 显示"第 X / Y 章 · Z%"。

### 底部菜单（4 项）

| 按钮 | 作用 |
|------|------|
| **目录** | 打开完整目录页，点击任意章节跳转；右上角可正序/倒序、强制刷新目录、批量缓存章节、批量加书签 |
| **朗读** | 让手机朗读当前章节（详见第 11 节） |
| **风格** | 阅读界面美化设置（见下文） |
| **设置** | 阅读功能设置（见下文） |

### 「风格」面板：把页面调成你喜欢的样子

- **字体**：字号大小（10–40）、字重（细/标准/粗）、字体选择（可导入自己的字体）。
- **间距**：行距、字距、段距、首行缩进。
- **边距**：页面上下左右留白。
- **颜色**：深色/浅色阅读模式、背景色色板、文字色色板——想保护眼睛就选深色背景。
- **其他**：中文排版、显示页脚（章节名/时间/页码）、**简繁转换**（原文/简体/繁体）。

### 「设置」面板：阅读功能设置

- **TXT 编码**：本地 TXT 小说打开乱码时，在这里切换编码（utf-8 / gbk / big5 等）。
- **阅读模式**：**分页**（一页一页翻，点击/滑动翻页，操作见上文"翻页操作"）/ **滚动**（连续滚动，上下滑动阅读、自动接续上下章，操作见上文"滚动模式"）。
- **横屏排版**：单页 / 双页（平板横屏看时）。
- **触控区域**：自定义 3×3 九宫格每个位置的动作——无动作 / 菜单 / 下一页 / 上一页 / 下一章 / 上一章 / 朗读上一段 / 朗读下一段 / 加书签 / 目录 / 朗读，可一键恢复默认。分页和滚动模式共用这套触控设置。

### 长按文字

长按正文选中文字后，菜单里除了常规的复制，还有 **「问 Kimi」**（需手机安装 Kimi App），可以把选中的文字发给 AI 提问（比如问生僻词的意思）。

### 离线缓存：没有网络也能看

1. 阅读时点顶部 **「•••」→「缓存章节」**。
2. 输入要缓存的起始/结束章节（默认当前章到最后一章）。
3. 缓存完成后，没网也能看这些章节。

也可以在「我的 → 缓存管理 → 离线缓存」里给整本书一键缓存、取消缓存，或导出书籍文件。

### 目录页（章节列表）

阅读时点「目录」进入，可以看到：

- 完整章节列表，**当前读到的章节高亮**，卷标题单独分组显示。
- 右上角：**↻ 强制刷新目录**（重新联网拉取）、**缓存**（进入多选缓存模式：全选、反选、缓存所选、缓存全部）、**正序/倒序**切换。
- 第二个标签页是**本书的书签列表**，点击跳转、可编辑/删除。

### 换源

- 阅读时点「•••」→「更换书源」→ 进入换源页，会显示这本书在其他书源上的结果。
- **整本换源**：把整本书换到另一个源（保留阅读进度）。
- **单章换源**：只把当前这一章换成其他源的内容（适合当前源本章内容有问题时）。

### 本地书籍的阅读（EPUB / PDF / MOBI）

- EPUB 书：App 自带三种阅读引擎（小说阅读 / 图文混排），可以在「设置 → 阅读设置」里切换，图文混排适合带插图的电子书。
- PDF 书：支持横竖屏切换、**原版/文字重排**、自动裁剪白边、加深/提亮调节。
- MOBI 书：自动识别排版阅读。

### 漫画阅读

从书源或在线书库里找到的漫画书（标记为漫画的书籍），点击后会进入专用漫画阅读器。漫画有两种主要阅读模式，在「我的 → 设置 → 漫画设置」里选择：

**模式一：条漫（从上到下滚动）**——适合手机竖屏，也是默认模式

- 和刷短视频一样，**手指上下滑动**，画面连续往下滚动，一张接一张看。
- 滚动到一话（一章）末尾自动接上下一话。
- 点屏幕中央呼出菜单后，底部有「上一章 / 目录 / 下一章 / 自动 / 刷新 / 换源 / 单页」按钮；中间还有进度条，拖动可跳到任意一页（显示"第 X/Y 页"）。
- 自动阅读：点底部「自动」按钮，每隔几秒自动滚下一屏，适合躺着看。

**模式二：单页（横向翻页）**——一屏一张图

- 在「漫画设置」里把方向选为「左→右」或「右→左」，并在阅读菜单里打开「单页」开关，就是每屏一张图、**左右滑动翻页**（左→右方向从左边开始读，右→左适合日漫从右边开始读）。
- 打开「单页」开关后，单页全屏显示（每屏一张图自动居中适配屏幕）。
- 这种模式也支持自动阅读、进度条跳页。

**两种模式通用的操作**：

- **双指捏合缩放**（0.5–3 倍）看图细节，**双击图片**放大/还原；放大后单指拖动平移。
- **点屏幕中央**呼出/收起菜单；菜单里有上一章、目录、下一章、自动阅读、刷新、换源、单页开关。
- **图片预加载**：在「漫画设置」里设置提前加载多少张图（1–20 张），翻页更流畅。
- **亮度调节**：阅读菜单里可直接调整图片亮度。
- 图片缓存可以随时在「漫画设置」里查看和清理。

## 8. 书源管理：App 的核心

「我的 → 书源管理」是 App 最重要的页面。书源列表每项显示：书源名称、网址、分组、权重、响应速度，右侧是**启用/禁用开关**（只有开启的书源才会参与搜索）。

### 导入书源

右上角「导入」按钮，支持三种方式（见第 1 节）：**本地文件 / 粘贴 JSON / 从 URL 导入**。导入时可以选择保留原名、分组、启用状态，也可以把新书源放进你指定的分组。

### 整理书源

- **搜索框**：按名称/网址/分组筛选书源。
- **排序**：按手动顺序、名称、URL、权重、更新时间、响应速度排序。
- **分组标签**：全部 / 已启用 / 已禁用 / 未分组 / 需登录 / 发现已启用 / 发现已停用 / 自定义分组。
- **按域名归类显示**开关：开启后按网站域名分组展示，方便找"哪家网站的书源"。
- **长按书源**：进入多选模式，可批量启用/禁用/置顶/置底/分组/导出/删除。

### 书源操作（每行 ⋮ 菜单）

- **登录**：书源网站需要账号时使用。
- **置顶 / 置底**：调整书源在搜索中的优先顺序。
- **启用发现 / 停用发现**：控制该书源是否出现在「发现」页。
- **搜索测试**：测试这个书源能否正常搜书。
- **规则调试**：高级功能，测试书源的具体解析规则。
- **AI 诊断修复**：书源坏了（搜不到书）时，让 AI 自动检查并修复它（需先配置 AI，见第 9 节）。
- **删除**：移除书源。

### 校验书源

书源多了之后，可以批量检查哪些还能用：多选模式下点**「校验」**，App 会逐个书源测试搜索、详情、目录、正文，完成后显示"通过 x · 失败 y"，失效的书源会自动筛选出来，方便你删除或修复。

### 编辑书源

点击任意书源进入编辑页，可以修改名称、网址、搜索规则等。**普通用户不需要动这些**，只有在书源失效且 AI 也修不好时，才需要找懂行的朋友帮忙。

### AI 生成书源：输入网址，AI 自动做书源

书源管理页右上角有 **「AI」** 按钮，进入"AI 生成书源"页。这个功能可以把**任何一个小说网站**变成一个书源，全程 AI 自动完成（需要先配置 AI 服务，见第 9 节"大模型配置"）。

操作步骤：

1. 在输入框里填**网站首页或小说站的网址**（例如某个小说网站的地址）。
2. 填一个**真实测试关键词**——建议填该网站上确实存在的一本书名（默认填"斗罗大陆"），AI 会拿它做真实搜索测试。
3. 点 **「开始生成」**，AI 会分 8 个阶段逐步分析，每步都有进度和结果摘要：
   - **首页与搜索入口** → **搜索规则** → **发现规则** → **详情规则** → **目录规则** → **正文规则** → **全链路校验** → **生成书源**。
4. AI 不是纸上谈兵，每一步都会**真实访问网站执行**（真的搜索、真的打开书籍详情、真的抓取目录和正文）。网站需要登录或有人机验证（验证码）时，App 会**暂停并弹出网页**，你在网页里完成登录/验证后，点"验证完成"，AI 继续工作。
5. 全部通过后，点 **「保存书源」**，可以修改自动生成的名称，确认后书源即新增并自动启用。
6. 如果该网址已经有书源了，会询问是否**更新**：更新会替换 AI 识别出的规则，但保留原来的分组、启用状态，而且**旧配置会保存为可回滚版本**（随时可以退回）。

过程中每一步都可以展开看细节，底部还有"整个过程"日志区，可点 **「复制」** 把完整过程复制下来（方便找人帮忙看）。没通过时点 **「重新运行」** 再来一次。

> 生成失败或对结果不满意？最常见原因是网站有特殊登录/验证机制没走完，重试一次并在弹出网页时完成验证即可。也可以换个测试关键词。

### AI 修复书源：书源失效了，让 AI 修

书源用久了容易"坏"（网站改版后搜不到书）。修复很简单：

1. 在书源管理页，找到失效的书源，点该行右侧的 **「⋮」→「AI 诊断修复」**。
2. App 进入"AI 修复书源"页，显示待修复的书源名和失败的阶段（如"搜索规则、正文规则"）。
3. 点 **「开始诊断并修复」**，AI 先重新校验现有规则，找出哪里坏了，然后针对失败的部分自动修复，并用真实搜索/正文再验证一遍。
4. 完成后点 **「应用修复」**，会提示改动了几个字段。**旧版本会保留**，如果修复后反而不好用，可以回滚：
   - 书源 ⋮ 菜单 → **「规则调试」** → 页面里有 **「回滚 AI 修复」** 按钮，恢复到修复前的版本。

> 提示：校验书源时发现的失效书源列表，正好可以逐个用"AI 诊断修复"处理。

### 规则调试（高级）

书源 ⋮ 菜单 → **「规则调试」**：输入关键词，可以单独测试这个书源的搜索、详情、目录、正文每一步是否正常，每步显示成功/失败和耗时。网站要登录/验证码时同样会弹出网页让你操作。这也是"AI 修复"的回滚入口所在地。

## 9. 我的：设置与工具

「我的」页签下有全部设置入口，逐个介绍：

### 设置

- **阅读设置**：自动缓存（阅读时自动提前缓存前后 N 章，0 表示关闭）；EPUB 阅读引擎选择。
- **语音朗读设置**：微软语音（Azure）配置——填端点地址和密钥，保存后阅读页的朗读面板就可以选"微软语音"音色（效果比系统语音更好）。
- **漫画设置**：阅读方向（条漫 / 左→右 / 右→左，详见第 7 节"漫画阅读"）、图片预加载数量、图片缓存清理。
- **搜索设置**：并发搜索数（同时搜索多少个书源，越大越快但更耗流量）、是否启用全部书源。
- **主题设置**：跟随系统（深色/浅色随手机自动切换）、深色模式开关、阅读界面是否随主题切换。
- **网络设置**：自定义 DNS、网络超时时间、HTTP 代理（一般用默认即可）。
- **关于**：版本信息。

### 大模型配置（AI 设置）

App 内置了 AI 助手（俗称 Agent），它连接你指定的大模型服务，帮你做三件大事：

| AI 功能 | 入口 | 作用 |
|---------|------|------|
| **AI 生成书源** | 书源管理 → 右上角「AI」 | 输入一个小说网站网址，AI 自动分析并生成可用的书源（见第 8 节） |
| **AI 修复书源** | 书源管理 → 书源 ⋮ →「AI 诊断修复」 | 书源失效时自动诊断并修复，可回滚（见第 8 节） |
| **AI 智能导入书籍** | 搜索 →「在线」标签 | 在线搜书找到网页后，"导入当前页"，AI 自动把整本书加入书架，不用书源（见第 5 节） |

以上功能都需要先在这里配置：

1. 点 **「新增」**，起个名字（如"DeepSeek"）。
2. 选择**供应商预设**（OpenAI / DeepSeek / OpenRouter / 硅基流动 / Ollama / 自定义），自动填入 API 地址。
3. 填入你的 **API Key**（在供应商官网申请的密钥）和**模型**名称（也可以点「获取模型」拉取服务商提供的模型列表选择）。
4. 设置请求超时时间（默认 120 秒，一般不用改）。
5. 点 **「测试连通性」**，提示"连接成功"即可使用。

可以保存多个配置（如一个免费的、一个付费的），用哪个点哪个，标"当前"的生效；支持删除不再用的配置。

> 如果你没有 API Key，可以在各 AI 服务商官网注册申请（多数有免费额度）。**不配置 AI 也不影响正常看书**——书源搜索、阅读、本地书、RSS 等核心功能都不依赖 AI。

### 在线书库管理

从云端书库下载书，支持三种来源：

- **OPDS 在线目录**：一种公共电子书目录格式，App 内置了公版书目录（免费经典名著）。
- **WebDAV**：你自己的网络硬盘（如坚果云）。
- **网盘**：支持百度网盘（需登录授权）。

添加后，在书架点 **☁ 按钮**进入"在线书库"，浏览目录、搜索书名、点击文件即可下载，下载后自动加入书架。下载后的书是本地书，删除书库配置不会影响已下载的书。

### 替换净化

有些小说网站正文里混着广告、无关文字，可以在这里**新建替换规则**：

- 输入"被替换的内容"和"替换成什么"（如把"本站最新域名：xxx.com"替换成空）。
- 可以设置规则作用于**正文**还是**标题**，也可以指定只对某些书生效。
- 支持正则表达式（高级用户用），普通用户直接写文字即可。
- 开启/关闭规则、批量操作、从文件导入、导出规则。

开启规则后，阅读时自动生效；也可以在阅读页「•••」菜单里快速开关净化。

### 字体管理

导入 .ttf / .otf 字体文件（一次最多 10 个），列表会预览每个字体的效果，支持重命名、删除。导入后在阅读「风格 → 字体」里选择。

### 阅读记录

统计你的总阅读时长、阅读天数、已读书籍数。

### 书签管理

所有书的书签汇总在这里：按书分组展示，支持搜索，每条书签可以**跳转**（打开书并跳到该位置）或**编辑**（修改原文/笔记、删除）。

### Web 远程管理

在电脑上远程控制手机阅读的功能，**当前版本暂未开放**，敬请期待。

### 备份与恢复

怕换手机丢数据？这里可以把所有数据备份起来：

- **本地备份**：备份到本地文件 / 从本地文件恢复。
- **WebDAV 云端备份**：配置服务器后，可以**自动备份（每 24 小时）**、云端恢复，多设备同步阅读进度。WebDAV 服务支持坚果云等。
- **恢复时忽略项**：可以勾选恢复时跳过哪些设置（如主题、封面配置等）。

备份内容包含：书架、书源、替换规则、分组、书签、订阅（RSS）、在线书库配置。恢复后提示统计结果。

### 缓存管理

- **章节内容缓存**：查看各本书缓存了多少章、占用多少空间，可单独清理或全部清理（清理不会删掉书和阅读进度）。
- **离线缓存**：给书源小说整本下载（见第 7 节"离线缓存"）。

## 10. 订阅（RSS）：看新闻博客

「订阅」页签可以订阅博客、新闻站的更新（RSS 订阅，一种标准格式，多数网站都有 RSS 链接）。

1. 点右上角 **「管理」** 进入订阅源管理。
2. 点「导入」或添加按钮，粘贴你喜欢的博客/新闻站的 RSS 地址（例如某个科技博客的 feed 链接）。
3. 回到订阅主页，点击订阅源进入**文章列表**，点文章阅读。
4. 文章可以**收藏**（星标），收藏的文章在"收藏"列表里统一查看。
5. 支持下拉刷新、自定义排序规则（高级功能，一般用默认即可）。

> 如果你不知道 RSS 地址是什么，可以先不碰这个功能，它和看书无关。

## 11. 朗读：让手机读书给你听

阅读页点底部 **「朗读」** 按钮，打开朗读面板：

- **播放 / 暂停 / 上一段 / 下一段 / 停止**。
- **语速调节**：0.5–2.0 倍速。
- **进度跳转**：可快进/快退或跳转段落。

### 朗读引擎与音色

朗读面板顶部可以切换引擎，不同引擎提供不同音色：

**引擎一：系统语音（默认，离线免费）**

- 使用鸿蒙系统自带的朗读能力，**默认提供两个离线音色：男声、女声**，无需联网、不耗流量，打开就能用。
- 部分设备还提供更多音色，可以点开音色列表查看，未下载的音色支持**下载后离线使用**（系统会显示下载进度）。
- 这是最省心、最稳定的选择，推荐日常使用。

**引擎二：微软语音（在线，效果更自然）**

- 微软在线朗读音色，音质更自然、表现力更强，提供多种中文音色可选（如"晓晓"女声、"云健""云希"男声等）。
- **需要付费订阅**：使用微软 Azure 语音服务，每月默认有 **50 万字免费额度**，超出部分按量计费（以微软官方价格为准）。需要先到微软 Azure 官网申请语音服务密钥，再在「我的 → 设置 → 语音朗读设置」里填入端点地址和密钥并保存，之后即可在朗读面板的"引擎"里切换到微软语音。
- 因依赖网络，朗读时请保持联网。

> 无论哪个引擎，朗读都会在你离开阅读页后继续播放，可以锁屏继续听。适合通勤、做家务时"听书"。

## 12. 常见问题

**Q：搜索不到任何书？**
先检查书源是否导入并启用（「我的 → 书源管理」，确认开关打开）；再试试在设置里调高"并发搜索数"；也可能是所有书源都失效了，用书源校验检查，或更新书源。

**Q：书源失效了，不会修怎么办？**
不需要自己修：书源管理 → 该书源 ⋮ 菜单 →「AI 诊断修复」，AI 自动诊断修复并验证（见第 8 节）。修复后不好用还可以回滚。

**Q：书源里搜不到我想要的书？**
用「搜索 → 在线」标签：网页搜索找到这本书，点"导入当前页"，AI 直接把整本书导入书架（见第 5 节）。不需要书源。

**Q：书源很少，想让更多网站也能搜书？**
书源管理 → 右上角「AI」→ 输入你想加入的小说网站网址 →「开始生成」，AI 自动帮你做出该书源（见第 8 节）。

**Q：打开书显示乱码？**
本地 TXT 小说乱码，在阅读「设置」里切换 TXT 编码（试试 gbk 或 utf-8）。

**Q：正文里有很多广告文字？**
在「我的 → 替换净化」里新建规则，把广告文字替换成空白；或者阅读时用「••• → 替换净化」快速开启净化。

**Q：某些网页打不开/提示需要验证？**
部分网站有安全验证（如 Cloudflare），搜索时如果遇到，App 会弹出"浏览器模式"，你在里面完成验证后，内容会自动带回来。

**Q：书的封面不好看？**
在书籍详情页点封面可以更换封面，或者点 ⋮ 菜单 →「换封面」。

**Q：想换手机，数据怎么迁移？**
用「我的 → 备份与恢复」备份到本地文件或 WebDAV 云端，新手机导入恢复即可。

**Q：读书时想保护眼睛？**
阅读页点「风格」，选择深色背景、调大字号和行距；也可以在系统设置里打开深色模式。

**Q：有些功能是灰色的/提示"开发中"？**
App 仍在完善中，部分功能（如 Web 远程管理、阅读记录的统计数字）会在后续版本开放。
